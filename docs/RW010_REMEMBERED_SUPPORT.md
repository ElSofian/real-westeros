# Remembered support in future political choices — M5

**Static-checked only; not engine-tested.** This source slice connects M4's native
public-support memories to later independent choices. It adds no runtime Python,
background scheduler, native override, new debt or legal reason.

## Actual choices

A recipient of a previous fulfilled public endorsement can remember its original
speaker when that person later proposes a **new** endorsement-for-gold agreement
(immediate or deferred quotation). The same personal memory can encourage an
original party to offer a voluntary repair in a **later** mediated dispute,
including an unrelated alleged affront. The old endorsement is not the new dispute
and no original dossier pointer, terms or settlement is consulted.

The existing shared AI cooperation value now applies **one ×1.5 factor** if the
actual decider remembers receiving support from this exact current counterpart.
This changes the relative weight of full-price acceptance or the 25-prestige repair,
not the underlying action or its outcome. Existing opinions, current commitments,
war burden, reserve, quotation/version/turn, personal consent and affordability
checks remain. Counteroffers, refusal and lapse retain their existing weights and
availability. Player and AI use identical execution effects, costs and conditions.
The client quotation and provider repair events append a localized personal reminder
only for the actual eligible decider with that memory. The player remains free.

## Knowledge and bounds

- Query **this decider's own** native `any_memory`, not the other character's memory
  or a globally indexed story. Require type `rw_public_support_received`, age below
  five years, and exact original participant identity. Given support, Crown
  recognition, another supporter or mere rumor cannot satisfy this test.
- Original known provider/client pairing is mandatory; a mediator, custodian,
  successor or other outsider cannot borrow another person's memory. No heir/house
  matching or inherited personal gratitude is introduced.
- Absence means no extra factor, not proof of unreliability. A forgotten or removed
  memory stops contributing immediately on reevaluation. The explicit age cap
  prevents a lingering expired memory from renewing this influence.
- One existential boolean, never a sum of all memories. Multiple records cannot
  multiply the factor or renew memory duration. No new memory is created by the
  query or reminder. Existing M4 creation/coalescing remains unchanged.
- No personal case receipt, reply, rumor holder list, native secret, proof or
  legal reason is read. Gratitude cannot establish innocence or authorize a sanction.
  No gold, opinion, flag, title, war, memory or native state mutation occurs here.
- Only these two future-choice families currently use this input. It is not a
  universal reputation system, heir guilt, complete political AI or measured
  performance optimization. Queries stay local to the decider at existing choice
  evaluation; native memory-list cost must still be measured in the final campaign.
