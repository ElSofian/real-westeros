## Interpretation and limits

- Missing file, parser/scope errors, setup_refused or precondition_failed: invalid
  diagnostic, not evidence of AI incapability.
- Failure means **no matching war found OR failed start**, per actual engine docs.
  It is not sufficient by itself to conclude the law removed a candidate.
- If the permissive control fails, the banned result is inconclusive. Inspect
  candidate trace, power/score and current prerequisites before attributing cause.
- Success proves the manually invoked native selector started a matching war;
  verify actual save CB, costs, callbacks and any defiance/response records.
  It does not establish regular scheduler discovery or autonomous initiative.
- Rejection must not start a war. A start despite always=no is a hard failure
  of the probe/assumed native contract, not permission to weaken its filter.
